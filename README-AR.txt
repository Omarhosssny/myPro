موقع عمر حسني، نسخة ثابتة جاهزة للنشر

1. فك ضغط الملف. ملفات index.html وassets يجب أن تكون في جذر النشر، وليس داخل مجلد إضافي.
2. قبل النشر النهائي: استبدل https://YOUR-DOMAIN.example بعنوان موقعك الحقيقي في ملفات HTML الخمسة وrobots.txt وsitemap.xml. يمكن استخدام نطاق Netlify أو Vercel المخصص لك حتى تشتري نطاقك.
3. Netlify: افتح Netlify Drop واسحب مجلد الموقع بعد فك الضغط. لا يوجد أمر build ولا حزم مطلوب تثبيتها.
4. Vercel: ارفع محتويات هذا المجلد إلى مستودع Git ثم Import Project. اختر Other. لا تستخدم Build Command وحدد Output Directory بالقيمة . ثم Deploy.
5. Railway: هذه ملفات ثابتة. استخدم خدمة static server أو nginx واضبط مجلد الموقع كجذر الملفات. Netlify أو Vercel أبسط لهذا الموقع، ولا يحتاج الموقع قاعدة بيانات.
6. الصفحات ملفات HTML فعلية: projects.html وservices.html وabout.html وcontact.html. لذلك تعمل الروابط المباشرة دون قواعد rewrite.
7. واتساب: الزر أسفل اليسار يفتح رقم +201144756606. الرسوم الخفيفة تتوقف مع إعداد تقليل الحركة.
8. نموذج التواصل مجهز لـ Netlify Forms: إرسال AJAX دون إعادة تحميل، وحقل honeypot لتقليل الرسائل المزعجة. لو فشل الإرسال تظل البيانات ويظهر رابط البريد كبديل، ولا يفتح تلقائيًا. نجاح النموذج يعني قبول Netlify للطلب، وليس ضمان وصول بريد الإشعار. الخطوات أدناه ضرورية.
9. SEO: عناوين ووصف لكل صفحة، canonical، Open Graph، Twitter، Person schema، robots وsitemap. بعد اختيار العنوان وإتمام النشر اربطه بـ Google Search Console وأرسل sitemap.xml. لا يوجد ضمان للترتيب أو الفهرسة.
10. المحتوى العربي ظاهر في HTML قبل تشغيل JavaScript. زر EN يبدل النص ويحتفظ باللغة أثناء التنقل في نفس جلسة المتصفح. لا توجد صفحات إنجليزية مستقلة للفهرسة.
11. للمراجعة محليًا افتح index.html. لا يحتاج العرض تثبيت أي مكتبات. يمكن أيضًا استخدام أي static HTTP server.
12. الشهادات خمس فقط كما قدمها عمر. شعارات العملاء أمثلة تصميمية وليست قائمة عملاء.

تفعيل وصول رسائل النموذج إلى البريد على Netlify:
أ. افتح مشروعك في Netlify ثم Forms واضغط Enable form detection. إذا كانت مفعلة بالفعل اتركها كذلك.
ب. بعد تفعيلها، ارفع هذه النسخة مجددًا من Deploys. يجب أن يتم النشر بعد التفعيل حتى يقرأ Netlify النماذج الموجودة في HTML.
ج. بعد نجاح النشر، افتح Forms وتأكد أن النموذج contact ظاهر في Active forms. النموذج موجود في الرئيسية وصفحة التواصل، وكلاهما يستخدم الاسم نفسه والحقول نفسها.
د. افتح Forms > Submission notifications > Add notification، واختر Email notification ثم النموذج contact، وأدخل oomat25063@gmail.com واحفظ.
هـ. عنوان الإشعار يجب أن يكون بريد عضو نشط في فريق Netlify أو عنوانًا أكد استقبال الإشعارات. إذا وصل بريد تأكيد إلى Gmail افتحه واضغط Confirm؛ لن تبدأ الإشعارات قبل التأكيد. لو الحساب لا يدعم تأكيد عناوين خارج الفريق ورفض العنوان، استخدم هذا البريد لحساب/عضو نشط في فريقك أولًا. لا تحتاج إضافة أشخاص آخرين.
و. افتح رابط Netlify الفعلي وأرسل رسالة اختبار بنفسك. تأكد من ظهورها داخل Forms > contact ومن وصول إشعارها إلى Gmail، وراجع Spam. Reply-to مضبوط على بريد الزائر بحقل email.
ز. لا يمكن التأكد من وصول البريد قبل هذا الاختبار على موقعك. راجع Forms > Usage وحدود خطتك من لوحة Netlify قبل الاستخدام؛ لا تفعل ترقية مدفوعة تلقائيًا.
ح. رابط المعاينة وفتح الملفات محليًا لا يستقبلان رسائل. هذا الإرسال مخصص لـ Netlify، وليس Vercel أو Railway دون إعداد خدمة نماذج أخرى.
ط. لتجنب نجاح وهمي على استضافة أخرى، يتأكد الموقع من نطاق netlify.app أو معالجة Netlify للنموذج وقت النشر. إذا استخدمت نطاقًا مخصصًا اربطه بمشروع Netlify نفسه وتأكد من تفعيل Forms وإعادة النشر.
